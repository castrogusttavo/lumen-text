Two pickers share the same fuzzy matcher:

- **Open file** (`Ctrl+P`) lists the files of the project.
- **Commands** (`Ctrl+Shift+P`) lists every command with its shortcut.

Type to filter, `Up` and `Down` to move, `Enter` to run, `Esc` to close. Other pickers use the same look: *Go to symbol* (`Ctrl+Shift+O`), *Symbol in project* (`Ctrl+T`), *Quick actions* (`Ctrl+.`) and *Choose theme*.

`Ctrl+G` asks for a line (`line[:column]`). `Ctrl+Shift+F` searches the project.

## All commands

The list below is generated from the editor's own command table, so labels and shortcuts are exactly what the palette shows. An empty shortcut means the command has none by default; you can bind one in `keybindings.json` (see [Keyboard shortcuts](/docs/shortcuts)).

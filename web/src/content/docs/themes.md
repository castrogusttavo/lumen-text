Lumen bundles **65 VS Code themes** (the same set Shiki ships) and highlights with TextMate grammars, so colors match what you know.

- **Choose a theme:** palette *Appearance: Choose theme…*. The arrow keys apply a theme live; `Esc` restores the previous one.
- **Follow the system:** *Appearance: Follow system light/dark theme*, or *Appearance mode* in the settings, with separate *Light theme* and *Dark theme* choices (defaults `github-light-default` and `github-dark-default`).
- **Interface colors:** *Derived* (default) keeps one calm, flat chrome for every theme; *From theme* uses the theme's own sidebar, tabs and status bar wherever the text stays readable.
- **Import Zed themes:** palette *Theme: Import Zed themes (min-theme etc.)* imports the Zed themes installed on your machine.
- **Write your own:** palette *Theme: Create custom theme (JSON template)* generates a template in your user themes folder.

Every text and background pair is checked against WCAG AA in every bundled theme.

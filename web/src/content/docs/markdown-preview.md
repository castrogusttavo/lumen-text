Open a Markdown file and press `Ctrl+Shift+V` (palette: *Markdown: Open reader beside*). The editor area splits into the source and a rendered reader.

- Updates as you type.
- Scroll sync in both directions.
- Highlighted code blocks and clickable links.
- The divider can be dragged; the share given to the source is remembered (`md_split`, between 0.2 and 0.8).

The reader needs a minimum width: in a narrow window the editor keeps all of the space.

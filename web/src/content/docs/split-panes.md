Split the editor with `Ctrl+\` (right) or `Ctrl+K \` (down). A row of four panes or a grid up to 3 by 2 is possible, six panes at most. Layouts are saved with the session.

| Action | Shortcut |
|---|---|
| Split editor right / down | `Ctrl+\` / `Ctrl+K \` |
| Focus pane 1 to 4 | `Ctrl+1` to `Ctrl+4` |
| Focus next / previous pane | `Ctrl+K Right` / `Ctrl+K Left` |
| Move tab to next / previous pane | `Ctrl+K Shift+Right` / `Ctrl+K Shift+Left` |
| Close focused pane | `Ctrl+K Shift+W` |

*View: Close split (merge all)* in the palette puts every tab back in one pane. The Markdown reader and the diff open inside the focused pane.
